## 6. General facts used beyond the shared statements of Section 2

1. k_v is a non-negative integer (gamma(C) - gamma_min and R(C -> D_v) are non-negative integers; P 356-357). Used
   in 43:cor:div to pass from "k_v != 0" to "k_v >= 1".
2. From the definitions of r, R and k_v only: the step from a state u of a cycle C to a state y with
   H(F u, y) = 1 gives R(C -> y) <= 1, and k_v <= gamma(C) + R(C -> D_v) - gamma_min (P 365-366).
3. Elementary facts on finite digraphs, as in P: a path that starts in a closed class stays in it (43:thm:crystal
   (3), 43:thm:levels Step 3; P 309-311, 451-452); a strongly connected set that contains K, when no edge leaves
   K, equals K (Step 3).
4. The complement maps cycles to cycles and edges of G_1 to edges of G_1. This is proved in place (43:lem:Z, from
   43:lem:cons(b) and cpl(x + e_j) = cpl(x) + e_j, as in P 433); `lem:sym` is not cited.
