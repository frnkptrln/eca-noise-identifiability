## 1. Setting and notation

Ring of n >= 3 cells, indices mod n. f(a, b, c) = bit (4a + 2b + c) of the rule number;
(F x)_i = f(x_(i-1), x_i, x_(i+1)).

    rule 142 = 10001110:  f = 1 exactly on the codes 001, 010, 011, 111
    rule  43 = 00101011:  f = 1 exactly on the codes 000, 001, 011, 101

Reading the two tables by the cases a != c and a = c gives the form used throughout [proved: compare with the
eight table entries]:

    (R)   if a != c:  f(a, b, c) = c            for both rules   (codes 001, 011, 100, 110)
          if a  = c:  f(a, b, c) = b            for rule 142     (codes 000, 010, 101, 111)
                      f(a, b, c) = 1 - b        for rule 43.

So the two rules agree on the codes 1, 3, 4, 6 and differ on 0, 2, 5, 7. Cycles are the periodic orbits of F.
G1 has the cycles as nodes and an edge C -> C' (C != C') iff for some state x of C and some cell j the orbit of
x + e_j (x with cell j flipped) ends on C'. A closed class is a strongly connected component of G1 without leaving
edge. r(C), V, gamma, S, k_c, k* as in `report_ring_size.md`, Section 3, and the note.

*This is the G1 of the report (edge iff V(C, C') = 1) [proved].* Steps of resistance 0 follow F and stay on a cycle.
So a path of total resistance 1 that starts on C consists of steps along C, one step from a state u of C to
F(u) + e_j = x + e_j with x = F(u) in C, and steps along the orbit of x + e_j; a periodic state on that orbit
lies on the cycle where the orbit ends. Hence V(C, C') = 1 iff some single flip of a state of C ends on C' != C,
and r(C) >= 2 iff no single flip of a state of C ends on another cycle.

**Maps.** (sigma x)_i = x_(i-1) (the pattern moves one cell to the right); C x = the complement of x. Both commute
with each other. *Notation.* The letter C is the complement map whenever it stands in front of a state, a map or
a cycle (C x, C sigma, C Z); elsewhere C, C' are cycles, as in the report (w(C), V(C, C')). In section 6 cycles
are called D to keep the two apart.

**Wall word.** delta(x) = d with d_i = x_i + x_(i+1) mod 2: d_i = 1 iff there is a wall between the cells i and
i+1. w(x) = number of ones of delta(x), the *wall count*. Elementary facts [proved: the parentheses]:

* (D1) delta(x) = delta(y) iff y = x or y = C x. (x + y is constant along the ring.)
* (D2) w(x) is even. (The sum of the d_i is twice the sum of the x_i mod 2.)
* (D3) delta(x + e_j) = delta(x) + e_(j-1) + e_j: a flip of cell j toggles the two walls next to cell j.

**Isolated and interior cells.** Cell j of x is *isolated* if it differs from both neighbours
(d_(j-1) = d_j = 1) and *interior* if it equals both neighbours (d_(j-1) = d_j = 0). In terms of runs (maximal
blocks of equal cells) of a non-constant state: an isolated cell is a run of length 1; a state has an interior cell
iff it has a run of length >= 3. In a constant state every cell is interior.

**Pairs in a word.** For a word d in {0,1}^n let

    P(d) = { i : d_i = d_(i+1) = 1 },     Q(d) = { i : d_i = d_(i+1) = 0 }.

So cell j of x is isolated iff j-1 is in P(delta x), and interior iff j-1 is in Q(delta x).

**Wall rules.** G184 and G226 denote the global maps of rules 184 and 226 on {0,1}^n:

    rule 184:  g(a, b, c) = 1 iff (b, c) = (1, 1) or (a, b) = (1, 0)     (a one moves right if the cell to its right is 0)
    rule 226:  g(a, b, c) = 1 iff (a, b) = (1, 1) or (b, c) = (0, 1)     (a one moves left if the cell to its left is 0)

g226(a, b, c) = g184(c, b, a). With the reflection (rho d)_i = d_(-i): G226 = rho G184 rho.

**The crystal.** For 4 | n, x0 = (0011)^(n/4) (cells 0, 1 carry 0, cells 2, 3 carry 1, and so on) and X is the set of
its four rotations.

**Levels.** For n not divisible by 4, w- is the largest even number below n/2 and w+ the smallest even number
above n/2. w+ - w- = 2. (n = 2 mod 4: n/2 -+ 1; n = 1 mod 4: (n-1)/2 and (n+3)/2; n = 3 mod 4: (n-3)/2 and
(n+1)/2.)

## 2. Statements

**Theorem 1 [proved].** Let n >= 4, 4 | n, and let F be rule 43 or rule 142.

1. X is a cycle of length 4, and for every state x of X and every cell j the orbit of x + e_j returns to X. Hence
   no edge of G1 leaves X, and r(X) >= 2.
2. Every cycle C != X has a directed path to X in G1 with exactly |w(C) - n/2| / 2 edges; along the path the wall
   count moves by 2 per edge towards n/2.

Consequently {X} is the only closed class of G1.

**Proposition 2 (healing time) [proved].** Let n >= 4, 4 | n, x in X, and call cell j a *left cell* if
x_(j-1) != x_j = x_(j+1) and a *right cell* if x_(j-1) = x_j != x_(j+1) (every cell is one or the other). Let tau
be the least t >= 1 with F^t(x + e_j) in X.
Rule 43: tau = 1 for a left cell and tau = n/2 - 1 for a right cell.
Rule 142: tau = n/2 - 1 for a left cell and tau = 1 for a right cell.
(For n = 4, n/2 - 1 = 1.)

**Proposition 3 (entry cost) [proved].** Let n >= 4, 4 | n. For every cycle C != X, V(C, X) = |w(C) - n/2| / 2. The
largest value, n/4, is attained exactly by the cycles with 0 or n walls.

**Corollary 1 [proved, given Theorem A].** For n >= 4, 4 | n, both rules: S = {X} and gamma_min = m - 1 (m the
number of cycles).

**Corollary 2 [proved, given Theorem A].** For n >= 4, 4 | n, both rules: k_1 = k_3 = k_4 = k_6 = 0 and
k_0 = k_2 = k_5 = k_7 = 1; k* = 1.

**Theorem 2 [proved].** Let n >= 5, n not divisible by 4, and let F be rule 43 or rule 142. Let K be the set of
cycles with w- or w+ walls. Then K is a closed class of G1, every cycle has a directed path into K, and K is the
only closed class.

**Corollary 3 [proved, given Theorem A].** For n >= 5, 4 not dividing n, both rules: S = K, gamma_min = m - 1,
every code occurs on a state of a cycle of K, k_c = 0 for all c, k* = 0.

**Corollary 4 [proved, given Theorem A].** For rules 43 and 142 and every n >= 4: k* = 1 if 4 | n, and k* = 0
otherwise.

## 3. Lemmas

**Lemma 1 (wall map) [proved].** Let d = delta(x).

* Rule 142: (F x)_i = x_i + d_i (1 - d_(i-1)) mod 2 (cell i changes iff there is a wall to its right and none to its
  left), and delta(F x) = G226(delta x).
* Rule 43: (F x)_i = x_i + 1 + d_(i-1) (1 - d_i) mod 2 (cell i changes unless there is a wall to its left and none
  to its right), and delta(F x) = G184(delta x).

*Proof.* x_(i-1) != x_(i+1) iff d_(i-1) + d_i = 1 mod 2. All sums below are mod 2.

Rule 142. By (R), if d_(i-1) + d_i = 1 then (F x)_i = x_(i+1) = x_i + d_i, otherwise (F x)_i = x_i. So
(F x)_i = x_i + d_i (d_(i-1) + d_i) = x_i + d_i (1 + d_(i-1)), using d_i d_i = d_i. Then
delta(F x)_i = (F x)_i + (F x)_(i+1) = d_i + d_i (1 + d_(i-1)) + d_(i+1) (1 + d_i) = d_(i-1) d_i + (1 + d_i) d_(i+1).
The two terms exclude each other; the sum is 1 iff (d_(i-1), d_i) = (1, 1) or (d_i, d_(i+1)) = (0, 1), which is
rule 226.

Rule 43. By (R), if d_(i-1) + d_i = 1 then (F x)_i = x_i + d_i, otherwise (F x)_i = x_i + 1. The change
(F x)_i + x_i is 1, 1, 1, 0 for (d_(i-1), d_i) = (0,0), (1,1), (0,1), (1,0), i.e. 1 + d_(i-1) (1 + d_i). Then (the two constants 1 of cells i and i+1 cancel mod 2)
delta(F x)_i = d_i + d_(i-1) (1 + d_i) + d_i (1 + d_(i+1)) = d_i d_(i+1) + d_(i-1) (1 + d_i), which is 1 iff
(d_i, d_(i+1)) = (1, 1) or (d_(i-1), d_i) = (1, 0): rule 184. []

**Lemma 2 (the wall rules conserve the number of ones) [proved].** |G184(d)| = |d| and |G226(d)| = |d|.

**Lemma 4 (periodic wall words) [proved].** For G = G184 and for G = G226: a word d is periodic under G iff
P(d) is empty or Q(d) is empty. Moreover

    rule 184:  P(d) empty => G d = sigma d;          Q(d) empty => G d = sigma^(-1) d;
    rule 226:  P(d) empty => G d = sigma^(-1) d;     Q(d) empty => G d = sigma d.

(G d)_i = d_i d_(i+1) + d_(i-1) (1 - d_i) = d_(i-1). If Q(d) is empty: for d_i = 1, (G d)_i = d_(i+1); for d_i = 0,
d_(i-1) = d_(i+1) = 1 and (G d)_i = 1 = d_(i+1). In both cases G d is a rotation of d, P or Q is empty again, and
G^n d = d.
Conversely let G^T d = d, T >= 1. By Lemma 3(a), |P(G^t d)| does not increase with t and is periodic in t, hence
constant, so A(G^t d) is empty for all t >= 0, and therefore P(G^t d) = P(d) - t and Q(G^t d) = Q(d) + t.

**Lemma 7 (periodic states) [proved].** For both rules:

(b) on these states F acts as follows:

d_i (1 + d_(i-1)) = 1 + d_(i-1) (if d_(i-1) = 0 then d_i = 1), so (F x)_i = x_i + 1 + x_(i-1) + x_i = 1 + x_(i-1).
sigma and C map isolated cells to isolated cells and interior cells to interior cells, so both properties are
preserved.
(a) By (b) the formulas apply to every F^t x, and F^(2n) x = x: x is periodic.
Conversely, if F^T x = x then G^T(delta x) = delta(F^T x) = delta(x) by Lemma 1, so by Lemma 4 P(delta x) or

(c) If F acts on the family of u as sigma^(-1), then sigma^r u = F^t u for any t >= 0 with t = -r mod n. If F acts as

*Description of the cycles [proved: restatement of Lemmas 3(c), 4, 7, 8].* The periodic states form two families.
Family "no isolated cell" (all runs >= 2, together with the two constant states): its wall count is at most n/2,
because P empty gives 2w - n = -|Q| <= 0 (Lemma 3(c)); under rule 142 every wall moves one cell to the left per
step and the state is shifted to the left; under rule 43 every wall moves one cell to the right and the state is
shifted to the right and complemented (Lemmas 4, 7). Family "no interior cell" (all runs <= 2): its wall count is at
least n/2 (Q empty gives 2w - n = |P| >= 0); under rule 142 the state is shifted to the right and complemented; under
rule 43 it is shifted to the left. The two families meet exactly in the states with P and Q both empty, which are
the four states of X for 4 | n and do not exist otherwise (Lemma 8 for even n; for odd n, P and Q both empty would
give 2w = n by Lemma 3(c)). All periods divide 2n (proof of Lemma 7).
[remark] Transients can be read as the annihilation of patterns 0011 (rule 43) or 1100 (rule 142) of the wall word,
i.e. of an interior cell with an isolated cell (Lemma 3).

**Lemma 8 (the level n/2) [proved].** Let 4 | n. For both rules the periodic states with wall count n/2 are
exactly the four states of X. They form one cycle, on which F = sigma^(-1). More generally, for even n a state
whose wall word has neither a block 11 nor a block 00 is one of these four states and 4 | n.

*Proof.* Let x be periodic with w(x) = n/2 and d = delta(x). By Lemma 3(c), |P(d)| = |Q(d)|; by Lemma 7 one of
them is empty; so both are, i.e. d alternates: d = (01)^(n/2) or (10)^(n/2). From x_(i+1) = x_i + d_i: x is
a a b b a a b b ... or a b b a a b b a ..., with b = 1 - a, which closes up on the ring iff n/2 is even. These are
the four rotations of x0. They contain only the codes 001, 011, 110, 100 (each cell has exactly one equal
neighbour), on which f(a, b, c) = c by (R): F = sigma^(-1), which permutes the four states cyclically. []

## 4. Proofs of Theorem 1 and Propositions 2, 3

*Theorem 1, part 1.* X is a cycle of length 4 by Lemma 8. Let x be in X and j a cell. In x every cell has exactly
one equal neighbour, so cell j is neither interior nor isolated, and w(x + e_j) = n/2 (Lemma 6). The wall count
is constant along the orbit (Lemma 5), so the cycle on which the orbit of x + e_j ends consists of periodic states
with wall count n/2; by Lemma 8 these are states of X; a cycle contained in X is X. So no single flip of a state
of X leads to another cycle: no edge of G1 leaves X, and r(X) >= 2 (section 1: r(C) >= 2 iff no single flip of a
state of C ends on another cycle). []

*Theorem 1, part 2.* Let C != X be a cycle, w = w(C). By Lemma 8, w != n/2; w is even (Lemma 5) and so is n/2.
Let x be in C and d = delta(x).
If w < n/2: |P(d)| - |Q(d)| = 2w - n < 0 (Lemma 3(c)), so Q(d) is not empty: x has an interior cell j.
w(x + e_j) = w + 2 (Lemma 6). The orbit of x + e_j ends on a cycle C' with w(C') = w + 2 (Lemma 5); C' != C
because the wall counts differ. So C -> C' is an edge of G1.

## 6. Rings with 4 not dividing n

Throughout this section n >= 5 and 4 does not divide n. Then 2 <= w- < n/2 < w+ <= n - 1, and no cycle has wall
count n/2 (for n = 2 mod 4, n/2 is odd). The *lower level* is the set of cycles with w- walls, the *upper level*
the set with w+ walls, K their union. eps = n - 2 w- is 1, 2, 3 for n = 1, 2, 3 mod 4.

**Lemma 9 (the two levels) [proved].** (a) Every periodic state with w- walls has an interior cell and no isolated
cell; every periodic state with w+ walls has an isolated cell and no interior cell. (b) A single flip of a state of
a cycle of the lower level leads to a cycle of the lower or of the upper level; likewise for the upper level. So no
edge of G1 leaves K. (c) Every cycle of the lower level has an edge of G1 to a cycle of the upper level, and
conversely. (d) Every cycle has a directed path in G1 into K.

*Proof.* (a) For w(x) = w- < n/2, Q(delta x) is not empty by Lemma 3(c), so by Lemma 7 P(delta x) is empty. For w+
exchange the roles. (b) By (a) and Lemma 6 a flip of a periodic state with w- walls gives wall count w- or
w- + 2 = w+, and the wall count is conserved along the orbit (Lemma 5). (c) Flip an interior (isolated) cell, which
exists by (a); the cycle reached has the other wall count, so it differs from the one left. (d) A periodic state with
w < w- walls has an interior cell (w < n/2 and Lemma 3(c)); flipping it gives w + 2 walls (Lemma 6), and the orbit
ends on a cycle with w + 2 walls (Lemma 5), which differs from the cycle left. Likewise with an isolated cell and
w - 2 for w > w+. The even numbers outside {w-, w+} are <= w- - 2 or >= w+ + 2, so after finitely many edges the
wall count is w- or w+. []

**Lemma 10 (slides) [proved].** For every n >= 3 (divisibility by 4 plays no role). A *slide* is a single flip that leads from a periodic state to a periodic state
with the same wall count. If y' = y + e_j is a slide, the cycles of y and y' are equal or joined by edges of G1 in
both directions.

(a) Let x have no isolated cell and w >= 2 walls. Then a sequence of slides leads from x to a state x*
whose runs, read from some cell on, have the lengths (n - 2w + 2, 2, ..., 2).
(b) Let x have no interior cell and w walls, n/2 < w < n. Then a sequence of slides leads from x to a state x*
whose runs, read from some cell on, have the lengths (2, ..., 2, 1, ..., 1) (n - w runs of length 2, then 2w - n
runs of length 1).

*Proof.* y' is periodic, so it lies on its cycle, which is where the orbit of y + e_j ends; the same with y and
y' exchanged. This is the first statement.
(a) x is not constant and has w runs R_1, ..., R_w (cut the ring at a run boundary), of lengths r_k >= 2 with sum
n. If r_k >= 3 for some k >= 2, flip the first cell of R_k. Before the flip this cell differs from its left
neighbour (the last cell of R_(k-1)) and equals its right neighbour; after the flip it belongs to R_(k-1). The
new run lengths are r_(k-1) + 1 and r_k - 1 >= 2, all others unchanged: again no isolated cell, w walls, hence a
periodic state (Lemma 7). Do this for k = w, w-1, ..., 2 in this order, each time until r_k = 2. Then
r_2 = ... = r_w = 2 and r_1 = n - 2(w - 1).
(b) Number the runs as in (a), with a fixed cut: R_1, ..., R_w, of lengths 1 or 2, n - w >= 1 of them of length 2
and 2w - n >= 1 of length 1. If (r_k, r_(k+1)) = (1, 2)
for some 1 <= k < w, flip the first cell of R_(k+1): it joins R_k, and the lengths become (2, 1), all others
unchanged: again no interior cell, w walls, a periodic state. Each such step lowers the number of pairs k < k'
with (r_k, r_k') = (1, 2) by one, so after finitely many steps no adjacent pair (1, 2) is left; a sequence of ones
and twos without an adjacent pair (1, 2) is (2, ..., 2, 1, ..., 1). []

**Lemma 11 (from Z to its complement) [proved].** Let w = w- and

    z0 = 0^(eps+2) (1100)^((w-2)/2) 11        (cells 0, ..., eps+1 carry 0; then w - 1 runs of length 2, alternating 1, 0, ..., 1).

z0 has no isolated cell and w walls; let Z be its cycle. For both rules there is a directed path in G1 from Z to
C Z (the cycle of C z0), or Z = C Z. By the complement symmetry there is also one from C Z to Z.

*Proof.* For s = 1, ..., eps let y_s be z0 with the cells eps+2-s, ..., eps+1 set to 1. Its runs have the lengths
(eps+2-s, s+2, 2, ..., 2), all >= 2 because s <= eps, so y_s has no isolated cell and w walls and is periodic
(Lemma 7); y_s = y_(s-1) + e_(eps+2-s) with y_0 = z0. So z0, y_1, ..., y_eps is a sequence of slides.
y_eps = 00 1^(eps+2) (0011)^((w-2)/2) = sigma^2 (C z0), because C z0 = 1^(eps+2) (0011)^((w-2)/2) 00 and sigma^2 moves the
last two cells to the front.
Rule 142: on states without isolated cell F = sigma^(-1) (Lemma 7), so F^2(y_eps) = C z0: y_eps is on the cycle of C z0.
Rule 43: on states without isolated cell F = C sigma, so F^2 = sigma^2 there and y_eps = F^2(C z0): y_eps is on the
cycle of C z0.
By Lemma 10 consecutive states of the sequence lie on equal cycles or on cycles joined by an edge.
Symmetry: F C = C F and C(x + e_j) = C x + e_j, so C maps cycles to cycles and edges of G1 to edges of G1. []

*Proof of Theorem 2.* Let x1 be the state with run lengths (2, ..., 2, 1, ..., 1) (n - w+ runs of length 2, then
2 w+ - n runs of length 1) starting at cell 0 with a run of zeros, and Z+ its cycle (x1 has no interior cell, so it
is periodic).

Step 1 (lower level). Let D be a cycle of the lower level and x a state of D. By Lemma 9(a) and Lemma 10(a) (w- >= 2) slides
lead from x to a state x* with run lengths (eps+2, 2, ..., 2), i.e. x* = sigma^r z0 or x* = C sigma^r z0 for some r. By
Lemma 7(c), x* lies on Z or on C Z. Slides can be undone, so D has a path to Z' and Z' has a path to D for some
Z' in {Z, C Z} (paths of length 0 included). By Lemma 11, Z and C Z have paths to each other. Hence all cycles of
the lower level lie in one strongly connected component K0 of G1.

Step 2 (upper level). In the same way (Lemma 9(a), Lemma 10(b), Lemma 7(c)) every cycle D+ of the upper level has
paths to and from some Z'+ in {Z+, C Z+}. By Lemma 9(c), Z has an edge to a cycle D1 of the upper level, and D1 has
a path to Z+ or to C Z+; applying C, the cycle C Z has a path to the other one; since Z has a path to C Z, the
cycle Z has paths to both Z+ and C Z+, hence to every cycle of the upper level. Conversely every cycle of the upper
level has an edge to a cycle of the lower level (Lemma 9(c)), which is in K0. So K is contained in K0.

Step 3. No edge leaves K (Lemma 9(b)), so K0 = K and K is a closed class. Every cycle has a path into K
(Lemma 9(d)), so every closed class meets K and therefore equals K. []

*Corollary 3.* Theorem A gives S = K and gamma_min = m - 1. Codes: z0 contains 000 (eps + 2 >= 3 zeros), 001, 011,
110 and 100 (the run 0^(eps+2) is followed by 11 and preceded, cyclically, by 11); C z0 contains 111. A state of a

is also on a cycle of the upper level, has the other one. So every code occurs on a state of a cycle of S, hence
k_c = 0 for all c (see the proof of Corollary 2) and k* = 0. []

*Corollary 4.* Corollary 2 for 4 | n (n >= 4), Corollary 3 otherwise (n >= 5). []

  the level n/2 exists iff n/2 is an even integer; on it Lemma 3(c) forces P and Q to be empty simultaneously, which

  tagged [proved, given Theorem A] depends on them; Theorems 1 and 2 and Propositions 2 and 3 do not.

  of the lemmas, an independent direct computation of the closed classes, and comparisons with the stored data of
  the study; no statement tagged [proved] relies on them.
* **Who checked the proofs.** The session that wrote them, with the tests of section 7, and one adversarial second
  reading inside the same session by a separate reader with separately written test code (it had no access to the
  scripts of this folder). That reading found no false statement and no invalid step; it reported two small gaps of

  draft before these changes and its exhaustive tests stop at n = 14 to 16). No human reader, no peer review.
* **Known results; no claim of novelty.** The wall map (Lemma 1) and the conservation law (Lemma 5) are known for
  both rules, see `literature_addendum.md`, Part B. That rule 60 (the wall map) transforms rule 142 into rule 226,
  and that rule 142 conserves the number of blocks 10, is in Fukś, Complex Systems 16, 123-138 (read in full; the
  first is credited there to Boccara, Physica D 68 (1993) 416-426, not read). Both identities,
  f60 ∘ f43 = f184 ∘ f60 and f60 ∘ f142 = f226 ∘ f60, and the conserved number of blocks 10 for rules 43 and 142
  are in Fukś, arXiv:nlin/0502037v1 (eqs. 28, 29, p. 12; p. 7 and Table 1; journal version Fundamenta Informaticae
  78 (2007) 329-341, not seen), which the session saw as a search excerpt only and which was read in full on
  18 November 2026 by a reader outside the session (addendum, update of that date). Lemmas 3 and 4 in the form
  used here (translation of the two sets of pairs; "periodic iff no 11 or no 00") were not found written out.
